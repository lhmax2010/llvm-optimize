# 覆盖补足（产品比较前写明）
450个发货归档是已经转换的ELF：每项目3853转换成员+11原生；在这些输入上调用convert只能走原生跳过路径。因此不能仅凭450复扫加10归档（1093 bitcode）就声称3853个成员均已重新生成。

只读确认63号原构建的build/lib64仍保存全部225个发货归档对应的原始归档。78号10归档的旧输出SHA与当前发货T的10个归档SHA全部相同（reference-relationship.json）。为满足本任务全部3853转换成员的字节比较，在这10个完成后，对其余215个原始归档逐个在新临时副本中转换，逐归档/逐成员与已保存发货T比较；任一差异STOP，不修改比较规则。目标总计3853转换+11原生，不把D的已转换ELF检查误称为再次代码生成。

不构建RPM，不改原件。仍在同一12GiB/CPU400%服务、jobs=2，整个步骤包括前段共120分钟；每30秒内存看门狗。只删除本任务新复制的输入和已记录SHA/逐成员结果的本任务输出，以免超过5GiB临时上限；历史/当前产物全部保留。若任何准入/停止线触发不重试。
