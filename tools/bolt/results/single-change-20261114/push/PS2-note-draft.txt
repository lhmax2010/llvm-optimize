PS2: add the guarded BOLT clang pipeline

Relative to PS1, this patch set adds Part 2 without changing Part 1.
It introduces the certified BOLT profile, helper gates and x86_64
packaging pipeline. Its tree is identical to the original two-commit
hybrid-linkage plus BOLT tree c23914776684bf94fdd5961f447f7c24e7bb79bc.

Files added or changed relative to PS1:
- packaging/clang-bolt-helper.py
- packaging/clang-bolt-v2.fdata.xz
- packaging/llvm.spec

BOLT runs only on x86_64. ARM retains its previous build behavior;
only the inherited installed CMake module text change from Part 1
remains in ARM binary payloads. The BOLT Sources are unconditional
so generated Patch declarations remain visible on every architecture.
Disable BOLT in QB by changing the x86_64 bcond_without clang_bolt
to bcond_with clang_bolt (one line). Local builds can also use
--without clang_bolt. This disables BOLT, not hybrid linkage.
