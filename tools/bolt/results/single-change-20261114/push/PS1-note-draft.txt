PS1: hybrid LLVM linkage on x86_64

This patch set introduces Part 1 only. It uses shared LLVM/Clang
linkage for selected targets while keeping clang, lld and llvm-ar
statically linked to LLVM components, with a hybrid-link assertion.

Files changed:
- clang/cmake/modules/AddClang.cmake
- clang/tools/driver/CMakeLists.txt
- lld/cmake/modules/AddLLD.cmake
- lld/tools/lld/CMakeLists.txt
- llvm/cmake/modules/AddLLVM.cmake
- llvm/tools/llvm-ar/CMakeLists.txt
- packaging/llvm.spec

The build-policy changes take effect on x86_64. On ARM, the installed
AddLLVM.cmake and AddClang.cmake text changes; the new helper returns
without changing the ARM build behavior. See design decision 7.15.
To roll back this part, revert its seven-file diff; there is no new
project configuration requirement.
