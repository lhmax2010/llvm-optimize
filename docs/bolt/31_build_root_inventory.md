## 1. 范围、口径与盲区

- 全盘只读 `findmnt`、`df`、`du`：覆盖 `/`（含 `/var/tmp`、`/tmp`）、独立 `/home`、`/boot/efi`；没有发现第四块已挂载的本地物理盘。snap loop、tmpfs、proc 等不当作可放长期构建根的磁盘。只列 **>5 GiB（5,368,709,120 B）** 的相关目录；其他系统/个人目录不属于 LLVM/GBS 盘点范围。
